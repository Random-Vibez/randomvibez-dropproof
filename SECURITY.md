# Security and privacy boundary

DropProof is a browser-local static tool. It has no account, server API, database, analytics, external runtime assets, or network workflow. Records remain in the current browser/device and local JSON export is not encrypted. Do not enter secrets or use shared devices for private incidents.

The tool is a record-keeping aid only. It does not verify delivery, contact providers, determine liability, provide legal advice, or guarantee reimbursement. Report implementation issues through the RandomVibez repository security contact rather than including private incident details.
