# DropProof

DropProof creates a bounded, printable delivery-incident record for a missing, damaged, wrong, or late parcel. It is browser-local: no account, upload, server storage, analytics, or automatic contact.

Use `python3 -m http.server` for local preview. The public runtime is `index.html`, `app.js`, `styles.css`, `cookie-banner.js`, `randomvibez-logo.jpg`, and `.htaccess`.

This is not legal advice, delivery verification, or a refund guarantee. JSON backups are unencrypted.
